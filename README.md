## Run Locally

This is a static website, so no build process is required.

### Option 1 — Open directly

Open `index.html` in a browser.

### Option 2 — Local server

From the project folder:

```bash
python3 -m http.server 8000
```

Then open:

```
http://localhost:8000
```

## Deployment

The website is deployed using **GitHub Pages** from the `main` branch.

Custom domain:

```
www.abikumar.com
```

The `CNAME` file in the repository preserves the custom domain configuration.
