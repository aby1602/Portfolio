# South Geelong Review Dashboard

Website: https://www.abikumar.com/arm-e-space/

## Update a rating directly on the website

1. Open the site, select a date and enter the Google, Uber Eats and DoorDash star ratings (0–5).
2. Press **Save rating**. The overall score, graph and table update immediately.
3. Use **Edit** or **Delete** in the history table to correct an entry.
4. Use **Export my ratings** to save a CSV backup.

**Important:** Website edits are saved only to browser localStorage on that browser and device. GitHub Pages is static and does not provide a backend to write these entries to the public repository or sync them across devices. Clearing browser data may delete them. The initial ratings come from `arm-e-space/ratings.csv`, which is still a public baseline.

## Score

Unofficial custom score = round((Google × 0.5 + Uber Eats × 0.3 + DoorDash × 0.2) × 20).

This is not an official Grill'd KPI. Enter only ratings you've checked, not guesses.
